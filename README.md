# Simple Interest Calculator Project

This repository contains the code and project documentation for the Final Project: Introduction to Git and GitHub.

## Project Overview
This project includes standard repository documents (License, Code of Conduct, Contributing guidelines) and a Bash script (`simple-interest.sh`) that calculates simple interest based on user inputs.

## Files Included
- `README.md`: Project documentation
- `LICENSE`: Apache 2.0 License
- `CODE_OF_CONDUCT.md`: Project code of conduct
- `CONTRIBUTING.md`: Guidelines for contributing
- `simple-interest.sh`: Bash script to calculate simple interest
